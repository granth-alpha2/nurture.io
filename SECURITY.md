# Security policy

## Current status

LandmarkNav is in documentation-only Phase 0. No service is deployed and no production security response channel has been configured. Do not submit real personal data, credentials, camera images, or precise location traces as test fixtures.

## Reporting a vulnerability

Until a private reporting channel is configured, do not publish exploit details. Contact the project maintainers through the private channel configured by the repository owner. Include affected component, impact, and safe reproduction information. Do not include secrets or personal data.

## Security commitments

- See [security and privacy](docs/06-security-and-privacy.md) for the planned threat model and controls.
- Security issues affecting physical navigation safety are treated as release blockers.
- Supported versions and response-time commitments will be set before public deployment.
