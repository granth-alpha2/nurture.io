# Field-test protocol

The detailed protocol and release safeguards are in `docs/09-testing-strategy.md`.

## Phase 0 status

This file records the repository entry point only; field testing has not been conducted. Before testing, obtain informed consent, select safe familiar walking routes, recruit varied users including older adults, assign an observer, and establish stop conditions. Never ask participants to watch a screen while crossing. Do not commit raw camera images or precise personal location traces.
